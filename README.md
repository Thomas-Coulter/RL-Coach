# Rocket League AI Mechanics Analyzer & Coach

> A 3D telemetry processor and analytics engine that parses Rocket League replay files to evaluate player kinematics, detect mechanic attempts, and generate coaching feedback.

## Overview

This project provides an automated analytics pipeline for Rocket League. Instead of using heavy Computer Vision models on video recordings, it parses raw binary replay files (30 Hz network logs containing X, Y, Z coordinates, rotation quaternions and velocities) to evaluate movement efficiency, detect mechanic attempts (such as flip resets, flicks, and wave dashes), and supply data-driven feedback.
